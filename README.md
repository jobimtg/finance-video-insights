# finance-video-insights

把財經節目（目前只追「錢線百分百」）的逐字稿整理成個股統整報告 PDF，並以 LINE Flex 卡片通知。

- 只處理公開市場資料與公開節目內容，不含任何個人資料。
- 金鑰一律存在 GitHub Secrets，不寫入 repo。
- 第三方原始資料（例如 FinMind）不放進本 repo，只存在 GitHub Actions 快取。
- 觀點為節目內容改寫摘要，不構成投資建議。

資料來源：臺灣證券交易所、證券櫃檯買賣中心（政府資料開放授權條款－第1版）、FRED（Federal Reserve Bank of St. Louis）、FinMind。
